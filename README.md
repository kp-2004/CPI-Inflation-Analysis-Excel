# India CPI Inflation Analysis – Excel Project

## 📊 Project Overview

This project analyzes India's Consumer Price Index (CPI) to understand
inflation trends, category-level price movements, food inflation,
COVID-19 impact, and the relationship between crude oil prices and CPI.

## 🎯 Objectives

1. Identify the major CPI category contributing to the latest CPI index.
2. Analyze year-over-year CPI inflation trends.
3. Analyze food inflation and identify major category movements.
4. Examine CPI changes during and after the COVID-19 period.
5. Analyze the relationship between Indian crude oil prices and CPI categories.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel formulas
- Data Cleaning
- MoM Analysis
- YoY Analysis
- Correlation Analysis
- Dashboarding

## 🔍 Key Findings

- Pan, Tobacco & Intoxicants recorded the highest relative contribution
  in May 2023.
- YoY CPI inflation peaked at approximately 7% in May 2022.
- Spices recorded the largest absolute increase in the analyzed food categories.
- Health recorded the largest increase in the long-term COVID-period comparison.
- Crude oil showed only weak linear relationships with the analyzed CPI categories.
